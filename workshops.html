Developmental events designed to strengthen programming skills, prepare students for certifications, and support academic growth.

Ctrl + Alt + Defeat: Floor is Java

A developmental event designed for second-year students to strengthen their Java programming skills and deepen their understanding of essential programming concepts. The review session will cover important topics, provide opportunities for hands-on practice, and help participants prepare more confidently for their Java certification.

Ctrl + Alt + Defeat: Now you C++ me

Coding C++eason returns once again with review sessions designed for Computer Science students. This developmental event is primarily intended for freshmen and aims to strengthen their understanding of C++ programming through discussions, practice exercises, and guided problem-solving activities. It will also help participants improve their coding skills, reinforce important concepts, and prepare more confidently for their final examinations.

Pythonpalooza

Pythonpalooza is a developmental review session for Computer Science students, particularly second-year students preparing for Python programming and the upcoming ITS Python certification. The event will cover fundamental Python concepts, practical programming techniques, and helpful tips to improve participants’ coding skills, strengthen their understanding, and boost their confidence before taking the certification.
