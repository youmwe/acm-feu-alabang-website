# ACM FEU Alabang Student Chapter

A responsive organization website based on the approved FEU Alabang ACM wireframe and high-fidelity design. It is built with HTML, CSS, and vanilla JavaScript and is designed to work as a static website on GitHub Pages.

## Project structure

```text
ACM_FEU_Alabang_FinalProject/
├── index.html
├── about.html
├── officers.html
├── events.html
├── workshops.html
├── gallery.html
├── contact.html
├── css/style.css
├── js/script.js
├── images/README.md
├── PROCESS_JOURNAL.md
└── README.md
```

## Run locally

Open `index.html` in a browser, or open this folder in Visual Studio Code and use a Live Server extension. The site has no build step and no required packages.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload every file in this folder.
2. Open **Settings → Pages** in the repository.
3. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then select **Save**.
4. Wait for the deployment, then open the generated Pages URL. Keep the homepage named `index.html`.

## Customize

Replace the bracketed placeholder content in `index.html` with the approved organization information, officer details, event details, photos, logos, and social links. Main colors and layout rules are in `css/style.css`; mobile navigation and reveal animation are in `js/script.js`.
